# Singularr identity

Use **Singularr** for the owner workspace and **Singularr Requests** for the viewer portal. Pronounce the
name like "singular." Use `singularr` for a lowercase project identifier, `singularr.toml` for the
instance file and `singularrd` for the server binary.

See the [illustrated product and identity guide](./Singularr%20Event%20Horizon%20Guide.pdf) and the
[identity board](./Singularr%20Event%20Horizon%20Board.png).
[Download the complete identity kit](https://github.com/silenthooligan/singularr/releases/download/identity-v1.0/Singularr.Event.Horizon.Kit.zip).

## Choose a mark

| Placement | Master |
| --- | --- |
| Large, dark campaign surface | [Singularr display lockup](./Display/Singularr.png) |
| Large requester portal surface | [Singularr Requests display lockup](./Display/Singularr%20Requests.png) |
| Navigation on dark or light surfaces | [Compact lockups](./Compact), selecting the file named for the background |
| Browser tab | [Favicon](./Icons/favicon.ico) |
| Launcher | [512 px app icon](./Icons/Singularr%20512.png) |

Keep a quarter of the core diameter clear around a mark. Display SVGs embed the transparent raster
filaments and outline the lettering. Compact SVGs contain paths throughout.

## Color and typography

| Color | Hex | Role |
| --- | --- | --- |
| Space | `#0E0D15` | Main dark background |
| Surface | `#201D2B` | Raised panels |
| Orbit | `#BBA4FD` | Actions and requester endorsement on dark backgrounds |
| Starlight | `#F3F0F7` | Primary text |
| Ink violet | `#5B3D92` | Accent on light backgrounds |

Use the supplied wordmark artwork for the name. Set interface copy in DM Sans and identifiers such as
S02E03 in IBM Plex Mono. The font license notices accompany their files in [Type](./Type).

## Voice

The campaign line is **Escape container sprawl.** In the product, name the action and its scope. Use
**Request this episode** on the viewer button and **You requested Signal Coast, season 2, episode 3** on
confirmation. Keep service names and file details in the owner workspace.
