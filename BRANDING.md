# Singularr identity

Use **Singularr** for the owner workspace and **Singularr Requests** for the viewer portal. Pronounce the name like “singular.” Use `singularr` for a lowercase project identifier.

## Choose a mark

| Placement | Master |
| --- | --- |
| Large, dark campaign surface | [Singularr display lockup](./Brand%20assets/Display/Singularr.png) |
| Large requester portal surface | [Singularr Requests display lockup](./Brand%20assets/Display/Singularr%20Requests.png) |
| Navigation on dark or light surfaces | [Compact lockups](./Brand%20assets/Compact), selecting the file named for the background |
| Browser tab | [Favicon](./Brand%20assets/Icons/favicon.ico) |
| Launcher | [512 px app icon](./Brand%20assets/Icons/Singularr%20512.png) |

Keep a quarter of the core diameter clear around a mark. Display SVGs embed the transparent raster filaments and outline the lettering. Compact SVGs contain paths throughout.

## Color and typography

| Color | Hex | Role |
| --- | --- | --- |
| Space | `#0E0D15` | Main dark background |
| Surface | `#201D2B` | Raised panels |
| Orbit | `#BBA4FD` | Actions and requester endorsement on dark backgrounds |
| Starlight | `#F3F0F7` | Primary text |
| Ink violet | `#5B3D92` | Accent on light backgrounds |

Use the supplied wordmark artwork for the name. Set interface copy in DM Sans and identifiers such as S02E03 in IBM Plex Mono. The original font license notices accompany their files.

## Voice

The campaign line is **Escape container sprawl.** In the product, name the action and its scope. Use **Request this episode** on the viewer button and **You requested Signal Coast, season 2, episode 3** on confirmation. Keep service names and file details in the owner workspace.
